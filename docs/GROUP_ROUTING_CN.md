# 默认分组与多分组 Key

标准模式下，新建 API Key 默认使用全部公开标准分组，也可以在 Key 的分组范围中选择多个分组。专属分组仍须获得用户授权，套餐分组仍须有有效订阅；请求会重新检查权限，删除授权后不能继续使用。

升级启动时，迁移 `130` 增加 Key 的范围字段，迁移 `131` 创建一个公开、标准、倍率为 `1` 的全平台“默认分组”。如果已有同名的其他分组，则使用“默认分组（全模型）”。已有普通 Key 保留原来的单分组或未分组行为；自动创建的 Auth 计费技术 Key 改为全部公开分组。简化模式下，未指定范围的普通新 Key 继续使用原有未分组路由。

管理员需要在上游账号中显式勾选默认分组。迁移不会复制账号、移动原分组账号，也不会把原专属分组设为公开。全平台分组可以绑定 OpenAI、Anthropic、Gemini、Antigravity 和媒体服务账号，但账号自身的平台仍须是真实供应商平台。

“全模型”指这个分组可以路由不同供应商的模型。实际可调用的模型取决于已绑定账号、模型映射、渠道限制和价格配置；没有可用账号或缺少 OIDC 计费价格时，调用仍会失败。

创建与修改 Key 的接口支持以下字段：

| 范围 | 请求字段 | 行为 |
| --- | --- | --- |
| 全部公开分组 | `group_scope: "public"` | 动态使用当前公开标准分组 |
| 指定多个分组 | `group_scope: "selected", group_ids: [1, 2]` | 仅使用所选且当前仍有权限的分组 |
| 原单分组 | `group_scope: "single", group_id: 1` | 保留原单组路由 |

生成请求在预扣费前按模型与协议选择实际分组。分组按排序值、ID 的顺序尝试，保留各组独立倍率；一次已预扣请求不会通过跨组回退改变价格。OIDC 计费还会叠加 OIDC 倍率，保存本次价格快照，后续调整倍率不重算历史账单。

模型目录只合并该 Key 有权使用的模型。WebSocket 依据首条消息的模型选择分组，并保持会话分组；已创建的媒体任务、克隆声音依据资源原分组校验权限，同时继续要求用户和 Key 属于该资源。
