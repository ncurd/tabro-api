# 签到积分入口

启用 Auth 统一计费后，当天可签到时，只在顶部积分右上角显示红点。点击积分打开弹窗，在里面签到；完成后即刻更新余额、清除红点，保持弹窗打开。没有单独签到菜单或顶部签到卡片，弹窗底部的小按钮可打开签到记录。

跨域领取使用 Auth 已授权摘要签发的短期、身份绑定领取凭证，客户端不能指定奖励金额或有效期。记录链接携带验证过的 `TenantId` 与 `ExpectedSubject`，防止浏览器中的其他登录身份显示错误记录。API 的本地访问令牌不会转发到 Auth。

签到默认有效期为 30 天，个人和企业规则分别在 Auth 管理后台配置。企业奖励进入企业账户并分配给领取人。每批到期时间由 Auth 固定，到期后不再计入 API 展示的可用积分，也不能继续消费；客户端不自行累加奖励或估算余额。

部署顺序：先执行 Auth 的 `DailyCheckInExpiry` 数据库迁移并发布 Auth，再发布 API 后端与前端。旧 Auth 摘要不含该字段时，现有积分展示仍可使用。详细配置和迁移命令见 tabro-auth 仓库的 `docs/DAILY_CHECK_IN_CN.md`。
